This is my project completed for the class DATA301: Big Data where I examine whether sentences end with softer words in the word *Babička* by Božena Němcová. I took this project as an opportunity to learn deeply about parallel programming and NLP, so I used AI very rarely for code generation and never to write larger blocks of code. Although the project and final report had to meet certain academic requirements, the assignment was very open-ended, and little personalized feedback was provided by the instructors throughout the process. Because of these circumstances, I believe that this project is an accurate representation of my own scientific thinking and technical abilities.
